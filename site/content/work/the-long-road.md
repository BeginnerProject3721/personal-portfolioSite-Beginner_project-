### 목적과 기획

스크롤만으로 하나의 게임 속 여정을 경험하는 듯한 인터랙티브 웹사이트를 만들고자 했습니다. 방문자가 스크롤을 내릴 때 인물이 앞으로 나아가고 주변 풍경이 달라지도록 구성해, 직접 이야기를 진행하는 느낌을 주는 데 초점을 맞췄습니다.

전체 흐름은 한 인물이 초원과 숲, 사막, 설산 등 다양한 장소를 지나가는 여정으로 기획했습니다. 장면마다 색감과 분위기에 변화를 주면서도 인물의 이동이 이어지도록 해, 여러 풍경이 하나의 이야기로 연결되게 하고 싶었습니다. 마지막에는 인물이 하늘을 가르는 장면을 넣어 여정의 절정을 표현하고, 방문자에게 인상적인 마무리를 남기고자 했습니다.

### 본인 역할과 제작 과정

저는 작품의 전체 기획과 연출 방향을 정하고, 구현 결과를 확인하며 수정할 부분을 판단하는 디렉터 역할을 맡았습니다. 코드 구현에는 Claude를 활용했으며, 세부적인 개발 로드맵을 정해 기본 구조부터 세부 연출까지 단계적으로 발전시켰습니다.

<details class="work-process-detail">
<summary>장면 구성과 개발 순서</summary>

먼저 초원·숲·사막과 인물의 걷기 동작, 스크롤에 따른 장면 전환을 구현했습니다. 이후 설산·호수·폭풍을 추가하고, 마지막에 인물이 멈춰 칼을 뽑고 하늘을 가르는 흐름을 구성했습니다. 전체 흐름이 갖춰진 뒤에는 인물의 움직임과 칼의 궤적, 충격파, 빛과 날씨 효과를 다듬었습니다.

</details>

<details class="work-process-detail">
<summary>풍경 표현과 코드 구조</summary>

Three.js로 3D 장면과 카메라, 렌더링을 구성하고, GLSL 셰이더로 풍경을 표현했습니다. 별도의 이미지나 3D 모델 파일 없이 도형과 수학적 함수를 이용해 화면을 만드는 방식입니다.

예를 들어 아래 코드는 서로 다른 크기의 노이즈를 다섯 번 겹쳐 산과 사구 등에 사용할 불규칙한 윤곽을 만드는 함수입니다.

```glsl
float fbm1(float x) {
  float s = 0.0, a = 0.5;
  for (int i = 0; i < 5; i++) {
    s += a * n1(x);
    x = x * 2.03 + 17.1;
    a *= 0.5;
  }
  return s / 0.97;
}
```

반복할 때마다 노이즈를 더 촘촘하게 만들고 영향은 절반으로 줄여, 큰 굴곡 위에 작은 굴곡을 더합니다. 이를 통해 단순한 곡선보다 자연스러운 지형의 형태를 표현할 수 있습니다.

</details>

<details class="work-process-detail">
<summary>인물의 움직임과 마지막 연출</summary>

인물은 갑옷 형태의 도형들을 조합해 구성하고, 가장자리에 빛을 더해 실루엣을 드러냈습니다. 걷기는 뼈대와 IK를 이용해 발이 지면에 붙는 움직임을 표현했으며, 칼을 뽑고 휘두르는 동작은 자세 키프레임으로 구성했습니다.

하늘을 가르는 장면은 하늘만 별도로 그린 뒤, 베기 선을 따라 양쪽으로 밀어내고 틈 사이로 새벽빛이 나타나도록 구현했습니다. 짧은 시간 정지와 카메라 움직임을 함께 사용해 동작의 타격감을 강조했습니다.

</details>

<details class="work-process-detail">
<summary>결과 확인과 수정</summary>

구현된 화면을 확인하면서 의도와 다른 부분은 수정 방향을 정해 다시 요청했습니다. 여러 차례 수정해도 자연스럽지 않았던 망토는 제거하고 긴 칼집으로 대체했으며, 하늘이 열릴 때 화면이 지나치게 밝아지는 현상과 칼집이 다리에 겹쳐 보이는 부분도 조정했습니다. 실행 성능에 따라 해상도와 입자 수를 조절하고, ‘동작 줄이기’ 설정에 대응하는 기능도 포함했습니다.

</details>
